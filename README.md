# Quasar Client Companion

A client-side Minecraft mod that adds multi-channel chat with tabbed channels, filtering, and context menus for CDU (Play CDU) servers. Works alongside the Quasar server plugin.

## Features

- **Multi-channel chat** — Tabbed channels (party, global, etc.), filtering, collapsible tabs, unread indicators
- **Context menus** — Right-click usernames for PM, Ignore/Unignore, admin tools; right-click channel tabs to close or collapse
- **Custom chat UI** — Scrollbar, message history, persistent settings
- **Cross-loader** — Fabric and Forge (Minecraft 1.20.1)

## Requirements

- Minecraft 1.20.1
- Java 17
- [Architectury API](https://www.curseforge.com/minecraft/mc-mods/architectury-api)
- CDU server with Quasar plugin (mod activates when channels are available)

## Installation

1. Install Architectury API for your loader (Fabric or Forge)
2. Place the mod JAR in your `mods` folder
3. Join a CDU server with Quasar — the custom chat appears when you have channels
